# OpenFB Plugin для VS Code

OpenFB Plugin добавляет в VS Code интерактивный редактор диаграмм IEC 61499 Function Block (FBD) для проектов 4diac и ForgeLogic (файлы `.sys`). Также поддерживается загрузка проекта в среду исполнения OpenFB.

## Что умеет

- Открывает и визуализирует проекты IEC 61499 из `.sys` файлов как интерактивные диаграммы.
- Поддерживает pan/zoom, выделение и drag-and-drop блоков.
- Создаёт связи между портами (event/data) с валидацией совместимости.
- Удаляет блоки и связи (`Delete` и контекстное меню).
- Редактирует параметры блоков и OPC UA mapping (помечает входы и выходы как публикуемые через OPC UA сервер, используя формат, совместимый с ForgeLogic).
- **Мониторинг в реальном времени:** Подключение к работающему устройству FORTE для чтения значений портов (`Watch`), имитации событий (`Trigger`) и принудительного изменения переменных (`Force`) прямо из интерфейса VS Code.
- **Живой поиск блоков:** Мгновенный поиск в библиотеке блоков с отдельной строкой ввода, которая автоматически раскрывает подходящие папки.
- Сохраняет изменения проекта обратно в `.sys` с надежным парсингом (больше никаких потерянных связей или пропавших портов после сохранения).
- Генерирует `.fboot` и выполняет загрузку (deploy) в среду исполнения OpenFB.
- Показывает логи в webview и extension output.
- При загрузке проекта (deploy) предлагает создать `.fboot`, если файл отсутствует.
- При генерации `.fboot` спрашивает подтверждение на перезапись существующاих файлов.
- Автоматически обновляет панель `Библиотека блоков`:
  - после создания нового FB type.
- Поддерживает локализацию интерфейса панели (`ru`/`en`) через настройку `openfb.uiLanguage`.
- После смены языка в настройках сразу обновляет подписи кнопок, вкладок и текст на canvas в открытой панели.
- *Примечание: Текущая версия позволяет использовать только один вычислительный узел в аппаратной конфигурации.*

## Быстрый старт

1. Установите расширение в VS Code.
2. **Создание нового проекта**: Нажмите `Ctrl+Shift+P`, введите `OpenFB: Создать SYS проект` (или `OpenFB: Create sys project`) и следуйте подсказкам для генерации нового `.sys` файла с нуля.
3. **Открытие существующего проекта**: В проводнике (Explorer) нажмите правой кнопкой мыши на файл `.sys` и выберите команду **OpenFB: Открыть диаграмму проекта**.

## Настройки

- `openfb.fbLibraryPaths` — пути поиска библиотек `.fbt`.
- `openfb.host` — адрес OpenFB runtime.
- `openfb.port` — порт OpenFB runtime.
- `openfb.deployTimeoutMs` — таймаут deploy в миллисекундах.
- `openfb.uiLanguage` — язык интерфейса панели OpenFB (`en` по умолчанию).

## Локализация

- Локализация `package.json` (название команды в контекстном меню Explorer и описания настроек) задаётся через `package.nls.json` и `package.nls.ru.json`.
- Эти строки зависят от языка интерфейса VS Code (Display Language), а не от `openfb.uiLanguage`.
- Настройка `openfb.uiLanguage` управляет только языком панели OpenFB (webview) и применяется сразу после сохранения настроек.

## Последние изменения (v0.2.0)

- **Добавлен мониторинг в реальном времени:** Полная интеграция с протоколом 4diac FORTE (Watch, Trigger, Force).
- **Добавлен живой поиск:** Мгновенная фильтрация в панели "Библиотека блоков" с автоматическим раскрытием папок.
- **Исправлены критические баги сохранения/парсинга:** Решена проблема, из-за которой блоки теряли порты после сохранения. Внедрен нечеткий поиск типов блоков для надежной перезагрузки модели.
- **Исправлена работа с блоком START:** Виртуальный блок START теперь корректно отображается в UI, а его связи строго читаются и записываются в секцию `<Resource>`, что гарантирует 100% совместимость с 4diac IDE и предотвращает дублирование в XML.
- Обновлены диалоги генерации/загрузки `.fboot` с подтверждением действий.
- Улучшена обработка путей `Type Library` для нескольких `.sys` проектов.

## Требования

- VS Code 1.85.0+
