# Changelog

## [0.2.0]
*Release leads: Loushkin Felix Aleksandrovich, Lombrozov Andrei Vladimirovich, Astafiev Nikolai Georgievich*

- **Мониторинг в реальном времени:** Добавлена полная поддержка протокола 4diac FORTE. Реализованы функции `Watch` (чтение значений портов), `Trigger` (имитация событий) и `Force` (принудительное изменение значений переменных) прямо из интерфейса VS Code.
- **Живой поиск по библиотеке:** Добавлено поле поиска в панель "Библиотека блоков" с мгновенной фильтрацией и автоматическим раскрытием подходящих папок.
- **Виртуальный блок START:** Блок START теперь корректно отображается в интерфейсе как системный узел с портами (COLD, WARM, STOP). Его соединения записываются и читаются строго из секции `<Resource>`, что гарантирует 100% совместимость с 4diac IDE и исключает дублирование в XML.
- **Генерация кода и SYS:** Добавлена функция генерации шаблонов кода по блоку и корректная генерация нового `.sys` файла с нуля.
- **Критическое исправление генерации .fboot:** Устранено дублирование команд соединений и ошибки маппинга, приводившие к сбоям при деплое.
- **Стабильность сохранения (.sys):** 
  - Исправлен баг, из-за которого блоки теряли порты и превращались в "овалы" после сохранения.
  - Устранено создание вложенных тегов `<SubAppNetwork>` и дублирование маппингов при патчинге XML.
- **Исправления интерфейса (UI/UX):**
  - Исправлены баги нормализации координат и автоименования блоков при сохранении.

- Текст пустого canvas (`No nodes loaded`) переведен на i18n-ключ и теперь меняется вместе с языком панели.

## [0.1.2]
- Улучшен сценарий Deploy:
	- если `.fboot` отсутствует, показывается диалог с вариантами `Создать` / `Отмена`;
	- при выборе `Создать` выполняется генерация `.fboot`, затем продолжается Deploy.
- Улучшен сценарий `Создать FBOOT`:
	- если `.fboot` уже существует, показывается подтверждение `Перезаписать` / `Отмена`.
- Исправлено разрешение путей библиотек:
	- `Type Library` теперь обрабатывается как локальный путь текущего `.sys`;
	- исключено «перетекание» `Type Library` между разными проектами.
- После создания нового FB type автоматически обновляется панель `Библиотека блоков`, если она открыта.
- После сохранения настроек (изменения путей) автоматически обновляется панель `Библиотека блоков`, если она открыта.
- Исправлено отображение `Класс` у новых блоков, добавленных с помощью drag-and-drop из библиотеки.
- Добавлена модель языков алгоритмов (`AlgorithmLanguage`) с централизованным маппингом язык -> XML-тег при сериализации (`ST` -> `<ST>`, `Python` -> `<PY>`).
